# 近红外光谱化学成分预测

近红外光谱预处理、波段筛选、PLS、SVR、核岭回归及模型融合的建模与复现代码。

## 最终模型

- 原建模集542条，按指定名单排除19条，最终训练523条。
- 在完整光谱上计算SG一阶导数：窗口17点、多项式3阶、步长2。
- 选择1050–1450区间，共201个变量；横坐标单位沿用源数据。
- 使用训练数据拟合特征及目标标准化参数。
- RBF核岭回归：alpha=0.001，gamma=0.1/201。

官方136条验证样本上的提交模型结果：MAE=0.228839，SEP=0.280531，RMSEP=0.280976，R²=0.760055。
SEP采用预测误差扣除平均偏差后的样本标准差（ddof=1）。

## 复现

安装Python及依赖：

```bash
python -m pip install -r requirements.txt
python reproduce_final_model_standalone.py --data-dir "原始数据目录" --output-dir reproduction
```

原始数据目录应包含建模集/1.csv至542.csv、验证集/1.csv至136.csv，以及建模集化学成分.xlsx。每条光谱CSV无表头，第一列为950–1650、间隔2的横坐标，第二列为吸光度。化学成分表第一列为样本编号、第二列为化学值。数据未随当前上传副本提供。

独立复现脚本固定最终配置，不重新优化。需要重跑完整开发流程时，将数据放在脚本同一目录，依次执行：

```bash
python train_first400_compare.py
python optimize_spectral_models.py
python summarize_spectral_optimization.py
python train_submission_model.py
```

完整优化包含7212组候选的重复交叉验证，耗时高于最终拟合。脚本会更新建模结果目录；保留原结果时请在副本中运行。绘图代码使用Windows字体路径，其他系统需调整。

详细报告编写于官方答案公布前，其中“验证集缺少真实化学值”描述当时状态；本README和results中的官方验证指标为答案公布后的评价。

开发阶段使用前400条训练、401–542条排除9条后共133条作开发对照。最终训练包含这133条，开发指标不能作为最终模型的独立测试指标。19条异常候选来自目视筛查，并非全部已证实为测量故障。

官方答案公布后，只对此前保存的12个候选及提交模型作事后比较，没有据此重新调参。提交模型在该比较中MAE、SEP、RMSEP均最低，但候选训练量为390/400条，提交模型为523条，不能据此作同训练规模的算法优劣结论。
